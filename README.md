# היער הקסום של עומר

משחק הרפתקה בתלת־ממד לדפדפן: יער מתמשך, החלפת צורה לסוס, עיט ודולפין, איסוף מרכיבים, משימות, בית וקישוטים. ממשק בעברית, שליטה במגע ובמקלדת ושמירה מקומית בדפדפן.

## הפעלה מקומית

נדרש Node.js. אין צורך להתקין תלויות.

```sh
npm start
```

פותחים http://localhost:5173. למשחק בטלפון באותה רשת משתמשים בכתובת המחשב ובפורט 5173.

## שליטה

WASD או חצים לתנועה, גרירה לסיבוב המצלמה, E לפעולה, רווח לקפיצה או עלייה ו־Shift לירידה. במגע: ג׳ויסטיק וכפתורים על המסך.

## GitHub Pages

התהליך `.github/workflows/pages.yml` מפרסם אוטומטית כל עדכון בענף `main`. בהגדרות הריפו, Pages צריך להשתמש ב־GitHub Actions.

הקבצים משתמשים בנתיבים יחסיים ולכן מתאימים גם לכתובת פרויקט ב־Pages. השמירה נפרדת בכל דפדפן ומכשיר; ההתקדמות מ־localhost אינה עוברת אוטומטית לכתובת האתר החדש.

## מצב הגרסה

גרסת משחק ראשונית. כולל אגמים ובריכות שנוצרים ברחבי היער. אין עדיין התנגשויות בעצים, צלילה לתוך קרקעית מעוצבת, משחק משותף או שמירה בענן. בדיקת ביצועים מקיפה על טלפונים וטאבלטים עוד נדרשת.
