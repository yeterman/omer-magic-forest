# היער הקסום של עומר

גרסה ראשונה של משחק תלת־ממד לדפדפן, בעברית. ללא שרת נתונים וללא התקנת תלויות.

## הפעלה מקומית

נדרש Node.js. מתוך התיקייה:

```sh
npm start
```

פותחים http://localhost:5173. בטלפון או בטאבלט באותה רשת Wi-Fi, פותחים את כתובת המחשב עם פורט 5173. ייתכן שתידרש הרשאת חומת אש. מומלץ מסך אופקי. ההתקדמות שייכת לכתובת האתר ולדפדפן שבהם שיחקתם.

## שליטה

- מחשב: WASD או חצים לתנועה, גרירה לסיבוב המצלמה, E לפעולה.
- רווח: קפיצה / עלייה; Shift: ירידה בתעופה או במים.
- 1, 2, 3: סוס, עיט ודולפין.
- מגע: ג׳ויסטיק שמאלי, גרירה על העולם לסיבוב המצלמה וכפתורי פעולה מימין.
- מעבר צורה צורך זרע / נוצה / פנינה. דולפין זמין במים. חזרה הביתה ולחוף אינה צורכת מרכיב.

## תוכן

יער הנוצר לפי אזורים, שלוש צורות חיה, איסוף מתחדש, שלוש משימות, בית עם שלושה קישוטים ופינת טיפול, אלבום גילויים ושמירה אוטומטית ב-localStorage.
הקן מצפון־מערב לבית, הארנבת משמאלו והאגם מצפון־מזרח. בתחילת המשחק מקבלים מרכיבים לשינוי צורה. פריטים מתחדשים אחרי 90 שניות.

## גבולות הגרסה

החיות והיער עשויים מצורות גאומטריות מקוריות. עדיין אין מערכת התנגשויות בעצים, עולם תת־מימי עשיר, צורות נוספות או סיפור מעבר לשלוש המשימות הראשונות. האזור האינסופי נוצר באופן קבוע לפי מיקום. הבית, האגם והמשימות הם מקומות קבועים.

## קבצים

`game.js` — העולם, הדמויות והמשחק; `style.css` — הממשק; `server.mjs` — שרת פיתוח מקומי. Three.js r170 כלול בתיקיית vendor תחת רישיון MIT. הגופן Heebo נטען מגוגל כשיש רשת, עם גופן מערכת כחלופה. המשחק עצמו אינו זקוק לשירות חיצוני.

`npm run check` לבדיקת תחביר. אין בשלב זה פרסום או הוסטינג.

## גרסה 0.16 — התנהגות חיות

השועל משוטט ליד הבית, האיילה נחה ומתרחקת מהתקרבות מהירה, ודג האגם שוחה בתוך המים. התקרבות שקטה עוצרת את חיות היבשה לשיחה; בזמן משימת הצמחים האיילה נשארת רגועה. החיות נשארות ליד נקודות המשימה. פתיחת תפריט משהה את ההתנהגות, וחיות במרחק מעל 55 מטר אינן מתעדכנות.

`npm test` מריץ סימולציות של גבולות תנועה, עומק השחייה, השהיה, מרחק ותגובה להתקרבות.
