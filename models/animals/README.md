# Animal assets supplied for this game

Kenney Cube Pets: GLB files from the user's local download. License CC0, included as KENNEY-LICENSE.txt. Source https://kenney.nl/.

Fox.fbx and Deer.fbx: supplied in Downloads/FBX-animals/FBX.
Dolphin.fbx and Fish1.fbx: supplied in Downloads/FBX-fish.
These FBX files have no accompanying license in the supplied folders. Their source/license is awaiting confirmation before public redistribution. This integration is for local preview until that is resolved.

The FBX files contain walk/gallop/idle or swim animations. Models are normalized at runtime, cloned with skeletons intact and loaded on demand. Kenney models have a deliberately stylized cube appearance.
